# Desafio Docker

Repositório de exercício prático sobre conteinerização com Docker.

## Objetivo
Registrar a implementação desenvolvida durante o desafio e apoiar a revisão dos conceitos de imagem, container, execução e configuração de aplicações.

## Como utilizar
Consulte os arquivos do repositório e siga os comandos e requisitos descritos nos artefatos disponíveis. Revise imagens-base e permissões antes de executar containers.

Material de aprendizagem, não uma imagem de produção mantida.
